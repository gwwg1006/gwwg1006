# 김명규크리에이티브

**3D 프린팅 제작 현장의 반복 업무를 소프트웨어와 AI로 연결합니다.**

김명규크리에이티브는 3D 프린팅·시제품 제작을 직접 운영하며, 문의 접수부터 견적·제작·배송까지 이어지는 실제 업무 흐름을 제품으로 만듭니다.

## OBA.RUN 2nd Hackathon

### MakerFlow AI

[**kimcre-ai-workflow →**](https://github.com/gwwg1006/kimcre-ai-workflow)

3D 프린팅 제작 의뢰를 **문의 → 요구사항 정리 → 견적 → 고객 응대 → 제작 진행 → 배송 안내**로 연결하는 AI 워크플로우입니다.

- 고객정보와 문의 원문은 로컬 우선 처리
- 외부 API에는 필요한 비식별 정보만 전달
- 소재·수량·색상·후가공·납기 조건 구조화
- 원가 규칙 기반 견적 초안 생성
- 단계별 고객 응대문 생성
- 가상 데이터와 Mock 모드로 재현 가능한 데모 제공

## What I build

- **현장 문제를 제품으로:** 실제 제작·출고 과정의 반복 작업을 발견하고 자동화합니다.
- **Privacy by design:** 고객정보는 로컬 처리와 최소수집을 우선합니다.
- **끝까지 연결:** 문의부터 결과 전달까지의 흐름을 설계합니다.
- **빠른 프로토타이핑:** 3D CAD·프린팅·하드웨어 경험과 웹 개발을 함께 활용합니다.
